# Resource & Ecology Audit A2 — Functional Classification and Lewdification

## Purpose
Define the minimum resource architecture needed to support the existing loops without creating a parallel NSFW economy or unnecessary new systems.

## Guardrail
Sexualization should be expressed through resource identity, traits, sources, presentation, and uses whenever possible. A new mechanical category is justified only when it serves a distinct existing gameplay function.

## Existing Loops to Support
- Exploration
- Base resource production
- Expeditions and rare returns
- Components
- Transmutation
- Equipment empowerment
- Quest and encounter rewards

## Recommended Functional Categories

### 1. Common Materials
Frequent infrastructure and production inputs.

**Status:** ADAPT

### 2. Special Materials
Less common materials used for specialized buildings, upgrades, equipment, transformations, and advanced content.

**Status:** ADD as a conceptual classification, not a new gameplay system.

### 3. Components
Dedicated inputs to Transmutation and equipment empowerment.

**Status:** KEEP

### 4. Unique Resources
Exceptional regional, quest-related, narrative, magical, or Wound-derived resources.

**Status:** ADAPT

## Sources
Resources may originate from:
- Exploration
- Production
- Expedition
- Quest
- Encounter

## Traits
Traits describe nature rather than creating parallel economies:
- Biological
- Botanical
- Magical
- Sensory
- Transformative
- Wound-Touched

Traits may later support recipes, buildings, events, quests, and presentation, but do not imply standalone systems.

## Explicit Scope-Creep Rejections
- Separate sexual-resource economy — CUT
- Separate NSFW inventory — CUT
- Separate sexual crafting system — CUT
- Biological as a mandatory mechanical category — CUT
- Magical as a mandatory mechanical category — CUT
- Wound resources as a standalone economy — CUT
- Full farming simulator — LATER
- Production specialization systems — LATER

## Working Model

Resource
- Category: Common Material / Special Material / Component / Unique Resource
- Source: Exploration / Production / Expedition / Quest / Encounter
- Traits: zero or more descriptive traits

## Conclusion
The recommended architecture preserves existing loops and permits strong structural lewdification without multiplying systems. The next step, A3, should populate the architecture with the smallest useful set of base resources rather than an exhaustive catalogue.
