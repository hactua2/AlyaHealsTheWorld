# Audit H — Combat, Skills, Equipment, and Rewards Integration

## Established foundations
Use the completed skills audit, established stat source-of-truth rule, effect lifecycle rules, and equipment-effect removal rule as authoritative constraints.

## Integration chain
Skill -> combat role -> stat interaction -> equipment/transmutation interaction -> encounter relevance -> reward destination -> future build choice.

## Requirements
Every combat reward must have a meaningful downstream use. Equipment should support playstyle changes. Transmutation should deepen specialization. Enemies/encounters should occasionally test or reward different tactical approaches rather than only increasing numerical difficulty.

## Scope guardrail
Do not create separate combat currencies, duplicate upgrade systems, or a second status-effect lifecycle.

## Pending decisions
Equipment slot count; build-switch friction; boss reward philosophy; encounter difficulty scaling; respec/accessibility policy.
