# Resource & Ecology Audit A5 — Processing and Consumption

## Purpose
Close the resource loop by mapping each recurring resource to a small number of clear consumption destinations without creating a large recipe tree or a separate processing system.

## Approved Consumption Destinations
1. Buildings
2. Equipment
3. Transmutation
4. Specialized Content / Unlocks

## Consumption Matrix

| Resource | Buildings | Equipment | Transmutation | Specialized Content |

## Functional Rules

### Common Materials
- Timber: primarily Buildings.
- Stone: primarily Buildings.
- Metal: Buildings and Equipment.
- Fiber: Buildings, Equipment, and limited Specialized Content.

Common materials should remain simple and should not become universal transmutation ingredients.

### Special Materials
- Essence is the broadest special resource, associated with power, vitality, specialization, magic, and transformation. It is versatile but should not become mandatory for ordinary progression.
- Nectar supports botanical production, consumption, transformation, specialized buildings, and limited transmutation.
- Musk represents sensory influence and specialized biological products; it may support buildings, equipment, transmutation, and specialized content.
- Estrus supports cycles, fertility, development, transformation, specialized buildings, transmutation, and unlocks rather than functioning as routine upkeep.

### Components
- Arcane Component: primarily Transmutation and Equipment empowerment.
- Organic Component: Transmutation, specialized Equipment, and selected Specialized Content.

### Unique Resources
Each Unique Resource receives an individually justified destination. No universal consumption pipeline is required.

## Processing Rule
Do not create a separate Processing System. Use the existing Base Production loop whenever a resource is converted or prepared.

Preferred chains:
- Resource -> Building
- Resource -> Equipment
- Resource -> Production -> Specialized Output
- Resource -> Production -> Component -> Transmutation

Avoid mandatory multi-stage refinement chains.

## Distribution Guardrails
- Common Materials: normally 1–2 important destinations.
- Special Materials: normally 2–4 destinations, justified by identity.
- Components: primarily Equipment and Transmutation.
- Unique Resources: one context-specific purpose unless content clearly requires more.

## Result
The economic loop closes through existing systems:
Acquisition -> Resources -> Buildings / Equipment / Production -> Components -> Transmutation -> Equipment Empowerment, with Specialized Content providing parallel narrative, transformation, event, and unlock destinations.

The next audit, A6, defines the minimum productive ecology that can generate these resources through flora, fauna, magical organisms, environments, and Wound influence without requiring a large biome simulator.
