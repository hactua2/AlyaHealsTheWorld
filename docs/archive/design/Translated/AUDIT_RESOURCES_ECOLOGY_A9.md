# Resource & Ecology Audit A9 — Integration with Base, Buildings, and Community

## Purpose
Connect the approved resource and ecology model to existing base-management loops without introducing parallel settlement simulators.

## Core Principle
The base should not merely convert abstract resources into larger numbers. Buildings and assignments should establish relationships with the productive ecology and provide stability, access, conversion, or specialization.

## Four Building Functions
All resource-facing buildings should primarily fit one of four functions:

### 1. Access
Unlocks or enables access to a resource source, expedition type, managed organism, or productive relationship.
Examples: facilities that permit cultivation, care, extraction, or safe interaction.

### 2. Stability
Provides predictable recurring output from a resource source that would otherwise be variable.
Examples: managed flora or organisms supplying Nectar, Musk, Estrus, Essence, or Organic Components.

### 3. Conversion
Uses existing Base Production to turn resources into Components or specialized outputs.
Rule: normally one meaningful conversion step; avoid multi-stage refinement trees.

### 4. Specialization
Changes what a resource relationship can accomplish, enabling specialized buildings, content, transformations, equipment applications, events, or narrative opportunities.

## Community Assignment Model
Assignments represent people performing ongoing relationships with ecology rather than repetitive manual chores.
Examples:
- tending sensory flora
- caring for productive organisms
- maintaining magical habitats
- processing biological materials
- preparing expedition materials

Assignments should remain compatible with the existing aptitude and time-based community system. A character's aptitude can affect efficiency, reliability, output variety, or access to advanced opportunities without making low-aptitude characters useless.

## Resource-to-Base Integration

| Resource Family | Typical Base Function |
|---|---|
| Timber / Stone / Metal / Fiber | Construction and infrastructure |
| Essence | Specialized facilities, upgrades, magical specialization |
| Nectar | Managed flora, consumption, specialized production |
| Musk | Sensory production, facilities, products, events |
| Estrus | Biological/cyclical facilities, transformation, specialized content |
| Arcane Component | Transmutation and equipment empowerment support |
| Organic Component | Biological processing, transmutation, specialized equipment/content |
| Unique Resources | Individually justified unlocks or landmarks |

## Building Design Guardrails
A new building should answer at least one question:
- Does it unlock access?
- Does it stabilize an existing variable source?
- Does it perform one needed conversion?
- Does it unlock a distinct specialization or content opportunity?

If the answer is no, the building is likely redundant.

## Lewdification Rule
Adult buildings and functions should use the same integration framework. Taverns, brothels, BDSM-oriented spaces, sensory gardens, aphrodisiac environments, and similar content should be evaluated as Access, Stability, Conversion, or Specialization rather than receiving a separate economy.

## Community and Narrative Integration
Ecological relationships can feed quests, events, character stories, recovery, transformation, and regional change. These are content consequences of existing systems rather than a fifth resource-consumption layer.

## Result
Base management becomes the mechanism by which the community turns unstable wild opportunities into reliable relationships and specialized possibilities. Resource systems, adult worldbuilding, and narrative therefore reinforce one another without requiring separate management games.
