# Buildings and Facilities

Every resource-facing building has one primary role:
- Access: unlocks a new capability or source.
- Stability: creates predictable output or reliability.
- Conversion: transforms inputs into outputs.
- Specialization: enables a focused option, build, or activity.

A standalone building must introduce a distinct player choice. Otherwise implement it as an upgrade, module, room, event unlock, or visual variation.

Use a small number of meaningful tiers. Prefer new options over percentage inflation.

Building schema: id, role, tier, requirements, costs, modules, inputs, outputs, assignmentSlots, unlockedCapabilities, upgradeTargets, gatingRule.

Facilities may host social, recovery, training, sensory, transformation, or specialized interaction content, but all use the same building architecture and economy.

Do not create parallel facility systems for different themes.
