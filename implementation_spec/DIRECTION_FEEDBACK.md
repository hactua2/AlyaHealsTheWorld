# Direction Feedback

The game exposes whether the player's long-term trajectory is improving or degrading conditions without a deterministic percentage.

## Global signal
DirectionState is qualitative and ordered, for example: Declining, Unstable, Balanced, Improving, Flourishing. Exact labels are presentation data.

## Local feedback
Regions and communities expose visible state changes that demonstrate where consequences occur.

## Rules
The global signal communicates trajectory, not guaranteed ending. Local changes communicate concrete consequences. Do not calculate or expose a universal completion percentage as the source of truth for the ending.
